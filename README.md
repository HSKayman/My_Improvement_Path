#My_Improvement_Paths/With_Course

Personal learning path: course work, solo practice, and small experiments across C, data structures, data science, machine learning, and deep learning. Source files include short purpose headers at the top where they did not already have a meaningful description.

## Repository structure

| Path | Focus |
|------|--------|
| `Application/` | Small utility scripts (lottery combinatorics, PDF text helper) |
| `C/` | Early C practice (Aug 2018): I/O, control flow, arrays, strings, files, sorting |
| `Data_Structures/` | Linked lists, stacks, queues, and related VY lesson exercises |
| `Data_Science/` | Visualization choice (PCP vs scatter matrix), K-means, IMDb scrape, Reddit NLP (LDA / n-gram / Word2Vec) |
| `Data_Science_Magnimind/` | Magnimind track: Python, statistics, ML labs, loan-default capstone |
| `Data_Science_Udemy/` | Udemy notebooks: preprocessing, viz, stats, linear models |
| `Deep_Learning/` | CNN / Keras–TensorFlow experiments |
| `DeepLearning.io_Coursera/` | deeplearning.ai specialization assignments (NN, CNN, sequence models) |
| `Machine_Learning_Coursera/` | Andrew Ng ML course exercises (`ex1`–`ex8`, MATLAB/Octave) |
| `Project_Euler/` | Project Euler solutions in C/C++/Python |
| `WebSite/` | Archived marketing-site example asset |

Subfolder READMEs (where present) keep the original Alone / With_Course notes and course links.
